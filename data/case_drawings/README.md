# 施工例 図面データ格納フォルダ (data/case_drawings/)

施工例の邸宅（鶴ヶ島市S様邸、ときがわ町K様邸など）の図面データ（平面図、立面図、矩計図、CADデータ等）を保管する専用ディレクトリです。

※本フォルダは `public/` の外にあるため、**Webサイト上に無断で公開されることはありません（安全に管理されます）**。

## 推奨フォルダ構成

```
data/case_drawings/
├── case1_鶴ヶ島市S様邸/
│   ├── 1F_平面図.pdf (または .jpg / .png / .jww / .dxf)
│   ├── 2F_平面図.pdf
│   └── 矩計図_断面図.pdf
├── case2_ときがわ町K様邸/
│   ├── 平面図.pdf
│   └── ...
├── case3_鶴ヶ島市A様邸/
├── case4_日高市I様邸/
├── case5_川越市Y様邸/
└── case6_行田市H様邸/
```

## AIパース工房での活用方法
1. **ControlNet Depth / LineArt 参照**: 平面図の壁芯や開口部を抽出し、3D鳥観図・真上からの3Dフロアプラン生成時の厳密な輪郭固定に使用します。
2. **住ま居る専用LoRA / プロンプト調整**: 実際の図面寸法と完成写真（無垢材・珪藻土）をペアにして学習・精度向上に使用します。
