# 住ま居る 間取りネタ帳・プランニング知見集 (Architect Notes)

## 1. 動線計画の黄金ルール
- **家事ラク回遊動線**: 玄関 ➔ パントリー ➔ キッチン ➔ 洗面ランドリー ➔ 浴室がぐるりと回遊できる動線。
- **ただいま動線**: 玄関土間 ➔ SIC ➔ 洗面手洗い ➔ ファミリーWIC ➔ LDK。リビングに汚れや荷物を持ち込ませない。
- **親子のふれあい動線**: 2階へ上がる際に必ずLDKを通る「リビングイン階段」。

## 2. 空間寸法・必要寸法の目安
- **書斎（テレワーク）**:
  - 独立個室: 2.0〜3.0帖（デスク幅1200mm以上＋本棚）
  - LDK内インナーコーナー: 1.0〜1.5帖（カウンター幅910〜1365mm＋奥行450mm）
- **家事コーナー**:
  - 1.5帖（アイロン台・ミシン台＋室内物干しワイヤー「pid 4M」＋収納棚）
- **兼用ワークコーナー**:
  - 2.0〜2.5帖（夫婦並列カウンター幅1820mm。PC作業と家事・書き物がシェア可能）

## 3. インテリア・照明・素材の知見
- **珪藻土と間接照明**:
  - コテ塗りの陰影を最も美しく引き出すコーブ照明・コーニス照明（2700K電球色）。
- **無垢床と家具**:
  - 吉野杉30mm無垢床の経年変化に調和するオーク・ウォールナットのオイル仕上げ家具。
